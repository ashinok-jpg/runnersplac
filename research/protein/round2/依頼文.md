# プロテインのデータ集めの依頼

添付の `protein-data-round2.csv` は、プロテインを比べるサイト（proteinplac）で使っているデータです。今は38行あります。このCSVを、下のルールのとおりに埋めて、行を増やしてください。

## やってほしいこと

### 1. 全商品の「味の種類」を埋める
- 公式サイトで、その商品で選べる味を全部「／」で区切って書く。例：`ココア／抹茶風味／黒糖きなこ`
- 「代表の味」は変えない。代表の味も「味の種類」に含める。
- 備考に「対象から外す」と書いてある行は、空のままでよい。

### 2. 中身がそろっていない6行を埋める
`winzone-whey`、`ogarmade-whey`、`ogarmade-soy`、`verifyst-whey`、`vitas-whey`、`reys-whey`

価格、1食の量、タンパク質、糖質、脂質、カロリーのうち、空いているところを埋める。

### 3. 商品を20〜30個増やす
- 日本で買える粉のプロテインに限る。ドリンク、バー、ゼリー、子ども向け、ダイエット向けの置き換え食品は入れない。
- 数が少ない種類を優先する：エッグ、ミルク、カゼイン、WPH、グラスフェッド、植物ミックス（えんどう豆など）、ヘンプ、ソイ。
- そのあとで、すでにあるブランドの別の商品や、楽天やAmazonのランキング上位のブランドを足す。
- すでにある商品（備考に「対象から外す」と書いた行も含む）は、新しい行として足さない。

## 列ごとのルール

| 列 | 書き方 |
|---|---|
| 商品ID | 英小文字とハイフン。`ブランド-商品`（例：`grong-soy`）。すでにある行のIDは変えない |
| 種類 | WPC／WPI／WPH／グラスフェッド／ソイ／カゼイン／ミルク／エッグ／植物ミックス／ヘンプ／混合 のどれか1つ。ホエイと別のタンパク質が混ざっていれば「混合」 |
| 代表の味 | 成分表示と価格を取った味。ノンフレーバーがあればそれを優先する。味つきの成分しか載っていなければ、その味を書く |
| 味の種類 | 選べる味を「／」区切りで全部 |
| 容量(g) | 代表の味でいちばん一般的な袋の容量（1kg前後が目安） |
| 通常価格(円) | セール前の通常価格（税込）。定期便やクーポンの価格は使わない |
| 価格確認日 | 実際に確認した日。`YYYY-MM-DD` |
| 1食の量〜カロリー | 成分表示に書いてある「1食あたり」の数字をそのまま書く。「100gあたり」しかなければ、1食の量で割り戻し、そう計算したことを備考に書く |
| 1食の糖質(g) | 「炭水化物」しか書いてなければ炭水化物の値を入れ、備考に「糖質欄は炭水化物の値」と書く |
| ロイシン(g/1食) | 書いてあるときだけ |
| 第三者認証 | 製品そのものが取っているアンチドーピング認証の名前（例：インフォームドチョイス）。会社だけが取っている認証は書かず、備考に回す。なければ「記載なし」 |
| 製造国・工場認証 | 「国内製造」「国内GMP認定工場」など、書いてあるとおりに |
| 人工甘味料の有無 | あり／なし。なしで別の甘味料を使っていれば「なし（ステビア）」のように書く |
| 溶けやすさ・味(1-5)、成分分析の公開 | 空のままでよい |
| 出典URL | 価格と成分を取った公式ページのURL。必ず入れる |
| 備考 | 価格をどこから取ったか、計算したこと、迷ったところ |

## 価格と成分を取る場所（この順で探す）
1. メーカーの公式サイト
2. メーカーの公式通販店（楽天やAmazonの公式ショップを含む）
3. 楽天24

## 守ってほしいこと
- **分からない値は空のままにする。推測で埋めない。**
- 終売の商品や、日本で売っていない商品も行は残し、備考に「対象から外す」と理由を書く。
- 効果の話（「筋肉がつく」など）は書かない。

## 返してほしいもの
1. 同じ列の並びのCSV（UTF-8）。すでにある38行と、新しく足した行の両方を入れる。
2. 変えた行と足した行の短い一覧。それぞれ、分からずに空にした項目があれば書く。
