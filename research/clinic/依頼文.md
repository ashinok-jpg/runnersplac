# 治療院データ集めの依頼文

下の「ここから」〜「ここまで」をそのまま別のAIに渡し、`clinic-data.csv`（見出しだけの空ファイル）も一緒に添付してください。
返ってきた CSV は `research/clinic/clinic-data.csv` に置き、`npm run clinic:build` を実行します。「注意:」が出た行は直してから main に push します。

---ここから---

ランナー向けの治療院紹介ページに載せる院の情報を集めてください。添付の CSV と同じ列で、1院1行の CSV を返してください。

## 対象
- 地域：東京23区と神奈川県。東京は23区以外は入れない。
- 種類（「種類」列にはこの4つのどれかをそのまま書く）：整骨院・接骨院／鍼灸院／整体・コンディショニング／スポーツ整形外科
- 選ぶ基準：公式サイトに、ランナー・マラソン・陸上、またはスポーツのけがへの対応がはっきり書いてある院。
- 件数：全部で40院くらい。23区で25院、神奈川で15院くらい。種類はどれか1つに偏らないようにする。
- チェーン店は、同じチェーンから3院まで。

## 守ってほしいこと
- 書くのは、公式サイト（または病院の公式ページ）で確認できた事実だけ。推測で埋めず、わからない欄は空欄にする。
- 口コミサイトやランキングサイトの評価・感想は使わない。「治る」「効く」といった効果の言葉は「院の紹介」に入れない。
- 閉院・移転していないか、公式サイトで確かめる。

## 各列の書き方
| 列 | 書き方 |
|---|---|
| 院ID | 半角英小文字・数字・ハイフン。例 `abc-seikotsuin-shibuya` |
| 都道府県 | 東京都／神奈川県 |
| 市区町村 | 例「渋谷区」「横浜市港北区」「川崎市中原区」「藤沢市」 |
| 住所 | 市区町村より後ろ（例「道玄坂1-2-3 ○○ビル2F」） |
| 最寄り駅・駅から徒歩(分) | 公式サイトの表記。例「渋谷駅」「5」 |
| 営業時間 | 公式サイトの表記を短く。改行の代わりに「／」 |
| 土曜の受付・日曜祝日の受付・19時以降の受付 | あり／なし（1曜日でも受付があれば「あり」。19時以降は、受付の終わりが19時より後なら「あり」） |
| 資格 | 「／」区切りで次の中から：医師／理学療法士／柔道整復師／はり師／きゅう師／あん摩マッサージ指圧師／アスレティックトレーナー／民間資格のみ |
| 相談できる部位 | 公式サイトに書いてある部位だけ。「／」区切りで次の中から：膝／すね／ふくらはぎ／アキレス腱／足首／足裏／太もも／股関節／腰／その他 |
| ランナー向けの設備・サービス | 公式サイトに書いてあるものだけ。「／」区切りで次の中から：ランニングフォームの分析／トレッドミル／インソールの作成／テーピング／走る再開までの指導／超音波エコー／MRI・CT／レントゲン／理学療法士のリハビリ |
| 健康保険 | 使える（病院）／使える場合がある（整骨院・接骨院、医師の同意で使える鍼灸院）／自費のみ |
| 初回料金の目安(円) | 自費の初回の料金（初診料・初回の施術料の合計）。数字だけ。病院や保険のみの院は空欄 |
| 院の紹介 | 100字以内。ランナー向けにしていることを事実で（例「院長が日本陸連公認の…」「トレッドミルで走り方を撮影して…」） |
| 出典URL | 情報を確かめた公式ページのURL |
| 確認日 | 調べた日。例 2026-11-10 |
| 掲載の経緯 | 「公開情報」と書く |
| 備考 | 迷ったこと、確かめられなかったこと |
